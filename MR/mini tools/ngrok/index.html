Arch Linux Guide
01. O'RNATISH

Ngrok-ni AUR-dan o'rnating

Arch Linux uchun rasmiy tarqatma yay yoki yay orqali yuklanadi.

yay -S ngrok
02. TOKEN OLISH

Dashboard-dan Authtoken oling

ngrok.com saytidan ro'yxatdan o'ting va Your Authtoken bo'limiga o'ting.

Token olish ↗
03. ULANISH

Tokenni terminalga kiriting

Bu orqali kompyuteringiz ngrok akkountingizga ulanadi.

ngrok config add-authtoken TOKENINGIZ
04. ISHGA TUSHIRISH

Lokal loyihani internetga chiqaring

Loyihangiz qaysi portda ishlayotgan bo'lsa (masalan 3000, 5173, 8080), o'sha portni yozing.

ngrok http 3000
ngrok config add-authtoken <YOUR_TOKEN>
Natijada ngrok bergan https://xxxx.ngrok-free.app havolasini istalgan kishiga yuborib, kompyuteringizdagi loyihani ko'rsatishingiz mumkin.
